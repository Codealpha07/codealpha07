## 🌟 Featured projects

### 📄 [IntelliDoc — Intelligent Document Analysis Platform](https://github.com/Codealpha07/IntelliDoc)
A document analysis platform focused on accurate text extraction and semantic retrieval.

**What I built:**
- A PDF parsing and OCR pipeline using PyMuPDF and Tesseract
- A transformer-based semantic relevance engine using BERT embeddings
- Dockerized services for scalable deployment

**Tech stack:** Python, PyMuPDF, Tesseract OCR, BERT, Docker

### 🌆 [CivicSense — Civic issue reporting platform](https://github.com/Codealpha07/civicsense) · [Live demo](https://civicsense-4861.onrender.com/)
A microservices-based platform for reporting and tracking civic issues with real-time maps and notifications.

**What I built:**
- Backend microservices (Node.js/Express, FastAPI)
- Real-time WebSocket dashboard and interactive maps
- AI-assisted issue detection (computer vision)

**Tech stack:** Node.js, Express, FastAPI, MongoDB, React, Leaflet

### 🔊 [AudiBliz — TTS Chrome extension](https://github.com/Codealpha07/AudiBliz)
A Chrome extension that converts web articles into natural-sounding audio, with multilingual support.

**What I built:**
- Content extraction and normalization for web pages
- Integration with TTS APIs for synthesized audio playback
- Lightweight, privacy‑focused UI for quick reads

**Tech stack:** JavaScript, Chrome Extension APIs, HTML/CSS
