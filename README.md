## 01 / THE ENGINEERING MINDSET

I’m interested in what happens between an idea and a working system.

How can a model recognize meaningful patterns? How should data move through a reliable backend? What makes a storage engine durable? How can software turn complex information into something people can actually use?

### 02 — AlphaDB

**A persistent key-value store in C++**

A Bitcask-inspired storage engine built to explore what happens beneath a database API — append-only writes, in-memory indexing, crash recovery, and concurrent TCP clients.

A project centered on storage fundamentals rather than another application-layer abstraction.

**Domain**

C++ · Storage Systems · Networking

[↗ View project](https://github.com/Codealpha07/AlphaDB--Key-Value-Store)
