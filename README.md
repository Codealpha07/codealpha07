## 🌟 Featured Projects

### [IntelliDoc](https://github.com/Codealpha07/IntelliDoc) — Intelligent Document Analysis Platform
An AI-focused document processing platform designed to extract, analyze, and semantically understand content from PDFs and documents.

Highlights:
- PDF parsing and OCR pipeline
- Semantic retrieval using embeddings and transformer-based search
- Dockerized deployment architecture

Tech: Python, PyMuPDF, Tesseract, BERT, Docker

### [CivicSense](https://github.com/Codealpha07/civicsense) — Civic Issue Reporting Platform
A platform for reporting civic issues with real-time location tracking, dashboards, and intelligent issue detection workflows.

Highlights:
- Microservices-based architecture
- Real-time dashboard and map visualization
- AI-assisted issue detection and data processing

Tech: Node.js, Express, FastAPI, MongoDB, React, Leaflet

### [AudiBliz](https://github.com/Codealpha07/AudiBliz) — Text-to-Speech Chrome Extension
A lightweight browser extension that converts web articles into spoken audio in multiple languages.

Highlights:
- Browser content extraction and processing
- TTS integration for seamless accessibility
- Privacy-friendly, lightweight UX

Tech: JavaScript, Chrome Extension APIs, HTML/CSS

### [AlphaDB](https://github.com/Codealpha07/AlphaDB--Key-Value-Store) — Key-Value Store in C++
A persistent key-value store inspired by Bitcask, built with append-only logging, in-memory indexing, crash recovery, and concurrent TCP server capabilities.

Highlights:
- Efficient append-only storage design
- Crash recovery and data integrity
- Concurrent client handling via TCP server

Tech: C++, Linux, Networking, Storage Systems
